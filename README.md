# AI-Assisted Excel Analysis Using ChatGPT

## Project Overview

This project explores how effectively AI can speed up data analysis in Excel using the **free version of ChatGPT through the Excel add-in**.

An analysis I expected to take a few days was completed in just **two hours** using simple, natural-language prompts.

The goal was to evaluate AI's efficiency while verifying the accuracy and reliability of its outputs.

## Tools Used

- Microsoft Excel
- ChatGPT add-in for Excel (Free version)

## Workflow

- Explored the dataset and identified data quality issues.
- Used natural-language prompts to create formulas, summaries, and visualizations.
- Refined chart titles, axis labels, data labels, and sorting for better readability.
- Identified and corrected unintended changes, including ROI percentage formatting being applied to the `Watch Verdict` column.
- Manually verified calculations and cross-checked the results before trusting the outputs.

## Validation Checks

| Check | Result |
|---|---|
| Row Count | Both tables matched at 43 movies. |
| Manual ROI Calculation | *The Godfather* ROI verified at 3942.00%. |
| Summary Reconciliation | Movie counts matched across the languages checked. |
| Filter Test | All displayed `Must Watch` movies had IMDb ratings of 8 or above. |

## Key Takeaways

- AI significantly reduced the time required for analysis.
- Clear prompts and iterative refinements improved the outputs.
- AI can introduce unintended changes that require human review.
- Manual verification and analytical fundamentals remain essential for reliable results.

## Conclusion

AI can accelerate analytical workflows, but speed alone is not enough. Understanding the data, questioning outputs, and validating results are equally important.
